# 字习 · 中文打字练习

使用 Chrome 打开 `index.html`，无需安装、注册或联网。

## 今日训练

首页按顺序推荐上次未完成的练习、错字复练、第一节未完成的系统课程。课程全部完成后推荐法条练习。使用“开始今日训练”进入现有练习，仍由输入开始计时。结束后卡片会更新建议，成绩留在原处，可以自行决定是否开始下一项。

## 系统课程

课程路线有 4 个单元、16 节课，包含输入入门、连打词语、句子与标点、场景篇章。进入系统课程会推荐第一节未完成的课，也可以自由选课。每课有具体练习提示和五星目标。

完整输入原文即可获得 1 星。准确率达到 85%、90%、95% 分别获得 2、3、4 星，同时达到 98% 准确率与本节速度目标即可获得 5 星。最佳成绩依次比较星级、准确率和速度。星级供自我练习参考，不限制后续课程。

旧版前三节的完成进度和成绩可以继续使用。新完成的课程和星级也会出现在练习记录中。

## 分级随机练习

默认进入常用词语。三级词库分别为：日常双字、生活办公（双字和三字混合）、常用短语（四字）。每组可选 10、20、30 词。常用单字可选 20、40、60 字。

“汉语句子”提供 48 条生活、学习和工作场景的完整句子，每句 10–30 个汉字（不含标点），随机抽取，每组可选 3、5、8 句。原文逐句分行显示，输入时连同中文标点一起输入，无需打换行或空格。

词库为人工整理的练习素材，并非权威词频排名。全部从本地素材抽取，组内不重复，换组优先使用上一组未出现的条目；素材不足以完全避开时会补回部分条目。单字、词语、句子不会被随机拆散或拼造。

- “换一组”生成新内容，“重练本组”保留原文并清零本次数据。
- 词语之间的间隔仅供阅读，不需输入空格。
- 输入法选字完成后才核对文字，支持退格和中间修改；多输入的内容会保留并提示。
- 练习中切课、换组、改难度或长度、重练时，会先暂停并询问是否放弃当前输入；点击当前课程不会清空。
- 切走标签或窗口时自动暂停，回来后手动继续。组字过程中离开会先停止计时，选字结束后进入暂停。
- 刷新或重新打开页面时，会恢复最近一次未完成的练习，包括原文、已提交的文字和用时。点击“继续练习”后重新计时。
- “练习记录”保留最近 100 次新完成的练习，可按类型筛选，查看用时、速度和准确率。旧版保留的完成进度和最近随机成绩仍会显示在侧栏。
- 在“练习记录”选择当前输入法。新成绩保存完成时的输入法标签，已有未带标签的成绩显示“未标记”。两项筛选可组合使用。趋势取筛选范围内最近一条具名输入法记录所属的类型和输入法，最多显示这个组合最近 10 次的速度和准确率。少于两次提示数据不足。“未标记”“未设置”和“其他”保留在记录里，不参与趋势。
- “定位错误”可选中输入框里第一个不一致的字符。“大字模式”同时放大原文和输入文字，并记住字号设置。

## 专项训练

- **键位盲打**以实体 QWERTY 键盘为主。切到英文小写，从 F、J 定位、中排基准键练到上排、下排和混合字母键。屏幕提示下一键和所用手指，熟悉后可以关闭提示。键位训练单独统计字符速度，中文练习仍使用自己的输入法。
- **错字复练**会从完成的中文练习中积累易错字词。词语练习收录目标词，句子练习收录目标字。每次选字或输入后只记录首次错位，避免把后续整串错位都记成独立错字。完成页可直接复练本次错字。首次在完整的一轮复练中打对会转为“待巩固”，另一轮完成的复练再打对才移出待练列表。再次打错后回到“待复习”。旧错字保留原有错误次数，并默认从“待复习”开始。
- **每日挑战**按北京时间为每天生成固定的三句汉语练习，每句为 10–30 个汉字。可重复挑战，最佳成绩先比较准确率，再比较速度。完成天数和连续记录保存在当前浏览器。所有用户同日题目一致，适合分享成绩和互相比较。

键位教学参考 [TypingClub 教学手册](https://static.typingclub.com/m/edclubdocs/media/pdf/Grade10_Typing_Handbook.pdf)及[联想社区的指法说明](https://club.lenovo.com.cn/thread-7943975-1-1.html)。[Emacs China 的指法讨论](https://emacs-china.org/t/topic/12132)涉及中文选字习惯和不同输入法的差异。针对错误复练参考 [Monkeytype 项目讨论](https://github.com/monkeytypegame/monkeytype/discussions/8262)中的考后复练设计。

## 文本训练与分段回顾

在“文本训练”中粘贴 10–600 个字符。换行用于分段，标点和句中的空格照原文输入。长段会按句末标点或长度拆开，以便读和练。未完成的输入、原文和分段计时保存在当前浏览器，可在关闭后继续。练习记录保留分数和素材标识，不保留原文。

自定义文本、系统课程的句子和篇章、随机句子、每日挑战完成后会显示分段回顾。报告优先推荐出错较多的段；没有出错时，才会根据可区分的每字用时提示明显较慢的段。组字或后补前文导致多段同时通过核对时，相应片段不单独估算用时。点击某段的“重练此段”，练完后可回到同一篇原文。重测结果与同模式下上次完成这篇原文的成绩比较。

## 统计说明

速度 = 当前正确字符数 / 有效练习分钟数（最短按 1 秒计算，包含标点）；准确率 = 正确提交字符数 / 总提交字符数，修改不会清除先前错误，删除不计为新输入。候选拼音不计入字符统计。不同长度、模式和输入法下的成绩不宜直接比较。

记录使用当前浏览器的 localStorage；清理浏览器数据、更换浏览器或页面地址可能导致记录不可用。

## 法条练习

已收录《中华人民共和国民法典》34 条和《中华人民共和国刑法》28 条。民法新增民事行为能力、撤销、代理、善意取得、格式条款、违约、夫妻财产和法定继承等主题。刑法新增共同犯罪、累犯、自首、立功、数罪并罚、缓刑及部分常见罪名。可按法律和条号选题，练完按条号顺序切到下一条收录条文。条号在原文旁边单独显示，不计入输入目标。正文中的款、项及其编号按原文输入，不必输入段落换行。练习进度和成绩保存在当前浏览器。

法条正文于 2026-11-24 核对。民法典底本为[最高人民法院转载全文](https://www.court.gov.cn/zixun/xiangqing/233181.html)，与[辽宁省审计厅转载全文](https://sjt.ln.gov.cn/sjt/sjzc/flfg/2026092410103250947/index.shtml)交叉比对。刑法底本为[国家税务总局政策法规库全文](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5212248/content.html)，使用据《刑法修正案（十二）》修正后的文本，收录条文与[国家统计局转载文本](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250311_1958931.html)逐条比对。界面上的主题标题仅用于选题定位。

## GitHub Pages 发布

网站是纯静态页面。将 `index.html`、`style.css`、`app.js`、`practice-data.js`、`course-data.js`、`training-data.js`、`passage-data.js`、`law-data.js` 和 `.nojekyll` 推送到打字网站仓库的 `main` 分支根目录。GitHub Pages 使用 **Deploy from a branch → main → /(root)**。项目站使用 `https://<账号>.github.io/<仓库名>/`，页面资产均使用相对路径。

网站使用系统字体，练习内容和功能由同站文件提供。访问 GitHub Pages 域名的网络可达性取决于访问者所在网络。线上站点与先前直接打开本地文件的练习进度各自保存在浏览器中。

## 开发与检查

纯 HTML / CSS / JavaScript。`practice-data.js` 保存词库与抽取逻辑，`course-data.js` 保存课程和评分规则，`training-data.js` 保存键位材料、每日题目及复练规则，`app.js` 管理交互。

`node --check app.js` 和 `node --check practice-data.js` 检查语法。

`node verify-random.cjs` 检查随机抽取约束，并生成 `.qa-check.html`。使用独立 Chrome 临时配置运行该页面，页面会显示浏览器交互检查结果；检查使用模拟组字事件，不能替代真实微软拼音、搜狗或双拼输入法实测。

页面参考 edclub / TypingClub 的分课练习与进度反馈思路，界面、词库和短句为本项目整理，未访问用户登录信息。
